# Trifusion

Trifusion is a modern web application built with **ReactJS** that allows users to seamlessly change background images by removing and adding new ones. Leveraging the power of `bgremoveapi` and HTML5 **Canvas**, Trifusion delivers fast and reliable background editing capabilities directly in the browser.

## 🚀 Features

- **Intuitive Interface** — Easily select and update backgrounds with a user-friendly UI.
- **Background Removal** — Automatically remove image backgrounds using bgremoveapi.
- **Canvas Editing** — Preview and adjust changes in real-time on an interactive canvas.
- **Flag System** — Toggle background changes with a simple add/remove flag mechanism.
- **Responsive Design** — Works smoothly across devices and screen sizes.

## 🛠️ Tech Stack

- [ReactJS](https://reactjs.org/) for building the frontend UI
- [bgremoveapi](https://www.bgremoveapi.com/) for fast background removal
- **HTML5 Canvas** for in-browser image editing and preview
